## 📖 Tentang Project

**Multipurpose** adalah tools berbasis Command Line Interface (CLI) yang dirancang untuk mempermudah berbagai tugas digital dalam satu aplikasi. Dibangun menggunakan **Python 3** dengan antarmuka terminal yang modern dan interaktif menggunakan library `Rich`.

Project ini dibuat untuk:
- 🎯 Pengguna yang menginginkan tools serbaguna dalam satu aplikasi
- 💻 Pengguna Termux / Linux / NetHunter
- 🔧 Developer yang membutuhkan utility praktis sehari-hari
